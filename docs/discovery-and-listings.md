**Short description (under 160 characters):**
Solve a new mystery every day with five progressive clues and six guesses. Play free, earn detective ranks, and explore unlimited practice.

**Long description (under 300 characters):**
Clue5 is a free daily mystery and deduction game. Identify a person, place, song, invention, movie or more from five progressively revealing clues. You have six guesses, score higher for earlier solves, and can explore a spoiler-free practice archive with a detective case-file theme.

**How to play:**
1. Examine your first clue.
2. Guess the mystery answer; reveal more clues if needed.
3. Solve before six incorrect guesses to earn detective points.
4. Return daily, or play unlimited practice without spoilers for upcoming daily cases.

## Google Search Console / analytics activation

1. Add **URL-prefix** property `https://clue-five-wheat.vercel.app/` in Search Console and verify ownership using the HTML file method (we can upload the supplied verification file to the repository).
2. Submit `https://clue-five-wheat.vercel.app/sitemap.xml` in Search Console > Sitemaps.
3. Vercel project `clue-five` > Analytics > Enable Web Analytics. A redeployment after enabling may be needed before tracking starts. Vercel analytics is currently not enabled until this step is done.
4. Use anonymized pageviews and referrers to measure acquisition. Custom daily/practice funnel events are instrumented, but require a Vercel plan with custom event support.
5. The analytics integration never sends guessed words, case answers, raw player identifiers or session tokens as custom event properties.

Please use the same primary URL for every directory submission to avoid fragmented listings. External directories may review submissions and determine whether to publish Clue5.
